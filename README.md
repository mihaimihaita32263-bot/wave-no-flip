# Wave No Flip

Gravity portals do nothing while you are in wave mode.

## Build (Windows)
1. Install Geode CLI + SDK (docs.geode-sdk.org) and Visual Studio with the C++ workload.
2. In this folder run:  geode build
3. Launch Geometry Dash, the mod appears in the Geode menu.

If the build complains about the "geode" version in mod.json, set it to the
version shown by `geode sdk version`.
